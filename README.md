# Giveaway Picker

Offline-first giveaway winner picker. Paste or import names, remove duplicates, draw winners and ordered backups with a secure RNG, watch a lot-drawing animation, keep a local log, download a draw record. Entrant data never leaves your browser.

Status and plan: `docs/HANDOFF.md`, `docs/PLAN.md`. Contributor/agent rules: `AGENTS.md`.
